Process

Three steps. Zero blind spots.

01
Ingest
Transactions arrive

Financial transaction data enters via the REST API or batch CSV upload. Argus builds a directed multigraph — every account is a node, every transfer is an edge with currency, amount, and timestamp.

02
Detect
The GNN scores every edge

A PNAConv + GINEConv Multi-GNN runs on the graph and assigns a laundering-probability score to each transaction edge. High-scoring edges cluster into alerts. The neighbourhood rescores in under a second on new data.

03
Investigate
Analyst closes the loop

Analysts open an alert, traverse the interactive graph, read the evidence flags — structuring, pass-through mules, velocity, off-hours timing — and mark Confirm, Review, or Dismiss. Every decision is persisted with timestamp and reason.
